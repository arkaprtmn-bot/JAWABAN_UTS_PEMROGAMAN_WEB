## Tentang Proyek
Website ini saya buat dari awal menggunakan dasar-dasar HTML5 dan CSS3. Di dalam project ini, saya fokus menerapkan struktur kode yang semantik, penggunaan *class* dan *tag selector* yang efisien, serta tata letak (*layout*) yang rapi menggunakan bantuan tag kontainer seperti `<main>` dan `<section>`.

## Struktur Folder & File
Di dalam project ini terdapat beberapa bagian file penting:
* `index.html` - File utama yang berisi seluruh struktur HTML website (mulai dari *hero panel*, bagian biografi, hingga tabel riwayat pendidikan).
* `style.css` - File khusus untuk mengatur tampilan, warna, *layout*, dan *styling* seluruh elemen web.
* `images/` - Folder tempat penyimpanan aset gambar (termasuk foto profil).

## Fitur & Bagian Website
1. **Hero Panel:** Bagian sambutan utama di bagian atas halaman dengan judul dan teks pengenal.
2. **Biografi & Profil Utama:** Berisi perkenalan singkat tentang saya sebagai mahasiswa Teknik Informatika, lengkap dengan foto profil berbentuk lingkaran (`border-radius: 50%`).
3. **Riwayat Pendidikan:** Disajikan dalam bentuk tabel HTML untuk merapikan informasi jenjang pendidikan.
